# Privacy

- **No accounts, no sync, no analytics, no telemetry, no tracking scripts, and by default no server-side database.** There's no infrastructure of mine for that data to even go to. (The only exception is the opt-in secret-collections feature described below, which is off unless a deployment sets up a database.)
- **Everything personal to you** — favorites, recent trips, Home/Work, offline map tiles, the in-progress-trip resume — **lives only in your own browser**, via IndexedDB and the Cache API. Clearing the site's data deletes all of it, permanently.
- **What leaves your device, and to whom** (only when the feature is used): search text/coordinates → **Nominatim**; route coordinates → **Valhalla** (and **OpenTripPlanner**, if configured); map tile coordinates → your tile host; GPS coordinates → **Open-Meteo** (weather badge) and **Mapillary** (if configured) — both opt-out via `config.js`; a pasted Google Maps link → this app's own tiny Cloudflare Worker, which forwards just that URL to Google.
- **One optional exception: secret spot collections** ([details](SPOT_COLLECTIONS.md)). Only on a deployment whose owner has bound a D1 database, and only after you type a collection's keyword. Then: the keyword you typed and the map area you're viewing → this app's own Worker; and anything you add (a name, a note, an optional link, a location) is stored in the owner's database and visible to everyone who knows the keyword. To limit abuse, the Worker keeps a hash of your IP address, salted with the date so it can't be linked across days — used only for rate limiting, never shown. Everyday searches are checked against a public list of keyword hashes on your own device and are **not** sent to the server. This device remembers which collections you unlocked (and their keywords) in `localStorage`; "Forget" in the Saved panel removes them. Disable the whole feature with `SPOTS_ENABLED: false` in `config.js`.
- The on-screen debug log (see [Troubleshooting](TROUBLESHOOTING.md)) is local and ephemeral — it never transmits anything, and is off by default.
- None of this is enforced against the *services themselves* — a public Nominatim/Valhalla/tile instance run by someone else can log requests like any other web request. [Self-host your own](SETUP.md) if that matters to you.
